# 🤖 The AI Roadmap — Interactive Presentation

An interactive, visual presentation designed to teach students the fundamentals of **Artificial Intelligence, Machine Learning, AI applications, and AI career pathways**.

Instead of delivering the lecture through a traditional PowerPoint presentation, this project turns the lesson into an **interactive web experience** where students can explore concepts, diagrams, quizzes, simulations, and learning paths directly in the browser.

---

## 🎯 About the Project

This project was created as a **live teaching presentation** for introducing students to Artificial Intelligence.

The goal was to make an otherwise theory-heavy introduction more engaging by combining:

* Visual explanations
* Interactive diagrams
* Animated interfaces
* Self-check quizzes
* Interactive decision trees
* Simulated AI workflows
* Learning roadmaps
* Industry examples
* Career-path exploration

The presentation guides students from the basic question **"What is AI?"** through different AI capabilities, real-world applications, development pathways, and recommended learning resources.

---

## 🧭 Presentation Structure

The presentation is organized as an interactive journey through several chapters.

### 01 — What is Artificial Intelligence?

Introduces AI using simple analogies and compares:

**Traditional Programming**

```text
Input Data + Hand-Written Rules → Output
```

with:

**Machine Learning**

```text
Input Data + Desired Answers → Learned Rules
```

The section also includes an interactive explanation of the major ingredients behind modern AI:

```text
Data + Algorithms + Computing Power → AI
```

and a quick self-check quiz about how systems such as ChatGPT generate responses.

---

### 02 — The AI Capability Spectrum

Introduces three commonly discussed levels of AI capability:

* **ANI — Artificial Narrow Intelligence**
* **AGI — Artificial General Intelligence**
* **ASI — Artificial Super Intelligence**

The section uses visual cards and an evolution scale to help students distinguish between today's task-specific AI systems and hypothetical future systems.

---

### 03 — AI in the Real World

Explores how AI can be applied across different industries, including:

* 🏥 Healthcare
* 🎓 Education
* 💰 Finance
* 🎮 Gaming
* 🌱 Agriculture
* 🛡️ Cybersecurity
* 🤖 Robotics
* 📣 Marketing & Retail
* 💻 Programming
* ⚖️ Law

Each area can be opened interactively to reveal examples, concepts, implementation steps, and career opportunities.

For example, the robotics section explains a simplified AI pipeline involving:

```text
3D World Mapping
        ↓
Object Recognition
        ↓
Path Planning
        ↓
Action
```

---

## 🧑‍💻 Choose Your AI Path

One of the central parts of the presentation is an interactive **AI career/pathway decision tree**.

Students answer questions about their interests and technical goals, and the presentation directs them toward different learning tracks.

### Path 01 — The Proactive AI User

Focuses on:

* AI-assisted workflows
* Prompt engineering
* Automation
* LLM tools
* AI productivity

The presentation includes an interactive prompt comparison showing how adding role, audience, and structural constraints can change a prompt.

---

### Path 02 — The AI Application Developer

Focuses on building software around AI models.

The presentation introduces concepts such as:

```text
Frontend
   ↓
Backend API
   ↓
AI / LLM
   ↓
Vector Database
   ↓
Application Response
```

It also includes an interactive API request simulator that demonstrates how developer-controlled parameters can become a structured request payload.

---

### Path 03 — The Machine Learning Engineer

Introduces the deeper technical path involving:

* Mathematics
* Statistics
* Neural networks
* Model architecture
* Optimization
* Backpropagation
* Gradient descent

The presentation contains an interactive backpropagation/gradient-descent simulation to visually demonstrate how model weights can be adjusted during training.

## 📚 Learning Roadmap

The presentation also provides a practical roadmap for students progressing from programming fundamentals toward modern AI development.

Example milestones include:

```text
Python Foundations
        ↓
REST APIs & Data Payloads
        ↓
Semantic Vector Databases
        ↓
Agentic Frameworks
        ↓
```

The roadmap includes estimated study hours and interactive progress tracking.
